# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| v0.2.0 | Yes |
| v0.1.0 | No (historical; released under PolyForm Strict 1.0.0, superseded by v0.2.0) |

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository from
the Security tab. Do not post suspected security vulnerabilities as public
issues.

Include the affected version or commit, a minimal reproduction, and any
relevant impact details. Do not include secrets or private data in a report.
